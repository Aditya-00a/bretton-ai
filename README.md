# SanctionLens

SanctionLens is a mock sanctions alert investigation agent demo built for the Bretton AI concept.
It reviews sanctions screening alerts, compares customer and watchlist evidence, recommends analyst routing, and drafts an audit-ready memo.

This is a concept demo using mock data only. It does not make real compliance decisions, replace human analysts, or provide legal advice.

## Stack

- Vite
- React
- TypeScript
- Lucide React icons
- Vercel static deployment

## Local Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```

## Deploy

```bash
vercel
vercel --prod
```
